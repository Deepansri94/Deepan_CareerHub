# Deepan CareerHub

Centralized career management hub — resumes, LinkedIn, website, and cover letters generated from a single source of truth.

## Structure
- `data/` — Source YAML files for profile, experience, skills, etc.
- `assets/` — Photos, certificates, logos
- `templates/` — Resume, LinkedIn, and website templates
- `generated/` — Output files (do not edit manually)
- `scripts/` — Generation scripts
- `changelog/` — Version history
